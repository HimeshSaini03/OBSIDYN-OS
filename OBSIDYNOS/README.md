# OBSIDYN Secure Execution Environment (SEE)

## Setup
1. Activate venv: `.\venv\Scripts\Activate.ps1`
2. Install Python deps: `pip install -r requirements.txt`
3. Install UI deps: `cd ui && npm install`
4. Run: `cd ui && npm start`

## Security Warning
Do not commit data/vaults or config keys to git.
